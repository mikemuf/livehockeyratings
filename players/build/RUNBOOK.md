# Player database runbook has moved

The player database (page, data, scripts and the full runbook) now lives in the private repository `mikemuf/player`. Nothing from it belongs in this public repository except `preview/index.html` and the stub at `players/index.html`.

To run the weekly update: add the repository `mikemuf/player` to the session with push access, clone it next to this one, and follow `RUNBOOK.md` at its root. If that repository cannot be added, stop and tell Mike; do not rebuild or publish the database from here.
